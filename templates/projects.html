ProverbIT

ProverbIT website
ProverbIT paper
Video (in Italian)
Python OpenRouter

ProverbIT is a benchmark designed to evaluate how Large Language Models handle the completion of Italian proverbs. The dataset includes 100 traditional proverbs, each paired with four carefully crafted alternative endings that challenge the model's understanding of meaning, rhyme, and logic. This project explores the discrepancy between the models' general familiarity with cultural content and their ability to apply it correctly in constrained tasks. The results offer insights into the types of errors LLMs make when interpreting idiomatic expressions.

The project was created in collaboration with Enrico Mensa (aka Enkk) and Lorenzo Zane.

SubVision

GitHub Repository
Go Python3 AWS SQS AWS DynamoDB Clerk Websockets

This project is an interactive Twitch integration that enhances live-stream engagement by combining real-time events with user-generated content. Viewers log in through Twitch using Clerk and provide a written physical description of themselves, which is securely stored in AWS DynamoDB. A Go-based backend coordinates the system while a Python event listener monitors the livestream for triggers such as new subscriptions or donations. When an event occurs, an image is automatically generated from the viewer’s description and displayed on the stream, creating a dynamic, personalized experience. Communication between the backend and listener is handled through AWS SQS.

Subcanvas is a website where an image is initially obscured and divided into small sections. Throughout the month, users a from specific Twitch chat can reveal sections of the image by subscribing or donating, with a new image presented each month. I developed the backend for this project, handling subscription and donation detection, and exposing data via APIs. MyIpTracker

GitHub Repository

MyIpTracker is a Python script that notifies the user when their public IP address changes. It does this by checking the public IP address and comparing it to the previous one, and if it detects a change, it sends a message to the user via Telegram bot.
